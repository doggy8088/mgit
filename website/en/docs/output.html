When a repository fails

Every repository runs by default (--keep-going); the summary lists each failure with its code and the run ends on the first one. --fail-fast stops there instead.

The summary and standard output

The summary goes to standard error, so mgit status -s > status.txt stays clean. --summary always prints it, and --quiet keeps git's own output only.

Color and glyphs

  • When output is redirected, or with --color=never / NO_COLOR, no ANSI escapes are emitted at all.
  • --ascii, or a non UTF-8 environment, uses Folder: … | Branch: … with identical behaviour.
  • Color is never the only carrier: headers, glyphs and the summary all read on their own.
