它怎麼找儲存庫

深度、worktree、submodule、symlink 與跨平台一致的排序

本章內容

規則先看它會動到誰深度

規則

  • 從當前目錄開始，逐層往下找（預設只找第一層，--depth 可調整）。
  • 目錄內只要有 .git 目錄或 .git 檔案都算儲存庫，因此 git worktree 與 submodule 都能正確辨識。
  • 找到儲存庫後不會再往下進入該儲存庫，避免把 submodule 或 vendored 的專案重複算進來。
  • 符號連結會被跟進，且以「看到的名字」為準；走訪過的實際目錄只會進入一次，連結迴圈不會無限迴圈。
  • 結果依名稱排序（忽略大小寫），順序在 macOS、Linux、Windows 上完全一致。
  • 如果一個儲存庫都沒找到，但當前目錄本身是儲存庫，就直接在該目錄執行 git。
