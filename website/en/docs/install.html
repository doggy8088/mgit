Three install paths, checksum verification, and building from source

Three paths

The installers detect the OS and architecture, download the matching release, verify SHA-256, then install, offering to add the directory to PATH.

macOS · Linuxcurl -fsSL https://raw.githubusercontent.com/doggy8088/mgit/main/install.sh | sh
Windows PowerShellirm https://raw.githubusercontent.com/doggy8088/mgit/main/install.ps1 | iex
npmnpm install -g @willh/mgit
npx @willh/mgitnpx

Node.js 20+; ships the official binaries for six platforms and runs no code on install (no postinstall).

Verify it yourself

shasum -a 256 -c mgit-aarch64-apple-darwin.tar.gz.sha256macOS
sha256sum -c mgit-x86_64-unknown-linux-musl.tar.gz.sha256Linux

所有檢查碼也彙整在 SHA256SUMS.txt。

Build from source

Needs Rust 1.85 or newer (rust-version is declared and CI enforces it).

cargo build --releasecargo
cargo install --path .cargo

Three environment variables for the installers

  • MGIT_VERSION: the release to install, for example 2.0.2 (default: latest).
  • MGIT_INSTALL_DIR: where the binary lands.
  • MGIT_DOWNLOAD_BASE: the base URL to download from (used by the tests).
