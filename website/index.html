一個指令，管好整個目錄下的所有 Git 儲存庫

不帶參數就等於對每個 repo 跑 git status -s；mgit pull、mgit fetch --all、mgit log -n 1 也一樣。乾淨的儲存庫不出聲，失敗的會被彙總成一個結束代碼。

  • 單一二進位檔，沒有執行期相依：不需要 Python、Node.js 或任何套件管理器。
  • 所有 git 參數以陣列傳遞、不經過 shell，沒有參數注入與 glob 展開的問題。
  • 發行檔附 SHA-256，官方安裝腳本先驗證再安裝。

應用程式、共用套件、範例、部署腳本、文件站各自是一個 repo，散在同一個工作目錄底下，彼此用相對路徑互相參考，卻沒有用 git submodule 綁在一起。這是 mgit 被寫出來的原因。

# 以前
for d in */; do (cd "$d" && git status -s); done

# 而且在 PowerShell 上要再寫一份，行為還不一樣

換成一個指令，而且三個作業系統上是同一個執行檔、同一組測試：

mgit

它不改變任何 repo 的內容，也不處理 repo 之間的版本關係。需要精確鎖定版本請用 submodule；需要單一 CI 與發佈流程，那是 monorepo 的問題。
