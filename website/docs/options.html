解析規則常用範例

解析規則

只認自己文件列出的選項；不認得的（-c、--git-dir…）直接轉給 git。第一個參數與 mgit 選項同名時（例如 --version），用 -- 分隔。

Option說明
-h, --help顯示說明並結束
-V, --version顯示版本並結束
-l, --list只列出找到的儲存庫（每行一個絕對路徑），不執行 git
-d, --depth <N>向下搜尋的目錄層數，預設 1
-q, --quiet不輸出每個儲存庫的標題，只留下 git 自己的輸出
--color <WHEN>auto（預設）、always、never
--no-color等同 --color=never
--ascii只使用 ASCII 符號（不使用 emoji），適合舊版終端機
--summary結束時一律印出統計摘要
-k, --keep-going某個儲存庫失敗仍繼續（預設行為）
--fail-fast遇到第一個失敗就停止
--allow-empty找不到任何儲存庫時仍以 0 結束
--之後的參數全部交給 git

常用範例

mgit --depth 2 fetch# 連第二層目錄的儲存庫一起更新
mgit --list# 確認到底會被操作哪些目錄
mgit -q log --oneline -n 1# 只看每個儲存庫的最新一筆
mgit --fail-fast pull# 一有衝突就停下來處理
mgit --color=never status# 輸出到檔案或 CI 日誌時關閉顏色
mgit --ascii# 舊版 Windows 主控台用純 ASCII
mgit -c core.pager=cat status# git 的全域選項照樣可用
注意分隔線

mgit 的選項只在第一個參數之前有效；一旦遇到不認得的參數，後面全部交給 git。
