Repository discovery

Depth, worktrees, submodules, symlinks and one ordering on every OS

The rules

  • The walk starts in the current directory (level 1 by default; --depth goes deeper).
  • A .git directory or a .git file both count, so git worktree and submodules are recognised.
  • The walk stops at a repository, so nothing vendored or nested inside it is counted twice.
  • Symlinks are followed under the name you see, and each real directory is visited once, so link loops terminate.
  • Results are sorted by name, ignoring case, identically on macOS, Linux and Windows.
  • If nothing is found but the current directory is itself a repository, git runs right there.
