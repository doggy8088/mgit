預設全部跑完（--keep-going），摘要列出每個失敗與其代碼，整體以第一個失敗的代碼結束；--fail-fast 則第一次失敗就停。

摘要與標準輸出

摘要寫到標準錯誤，所以 mgit status -s > status.txt 不會被汙染；--summary 可以要求每次執行都印出摘要，--quiet 則只留下 git 自己的輸出。

顏色與符號

  • 輸出被重導向、--color=never 或 NO_COLOR 時，完全不會有 ANSI 跳脫序列。
  • --ascii 或非 UTF-8 的環境會用 Folder: … | Branch: …，功能完全相同。
  • 顏色永遠不是唯一承載資訊的方式：標題、符號與摘要都能單獨讀懂。
